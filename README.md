# Kent Test Reasoning Practice

A free, static web app for practising 11+ **verbal** and **non-verbal reasoning** in the style of the Kent Test.

- Timed mock tests (verbal and non-verbal)
- Untimed topic practice with instant feedback and explanations
- Progress tracking, saved in the browser only (nothing is sent anywhere)
- 150 original questions, answers shuffled every time

**Disclaimer:** all questions are original practice items written in the style of the Kent Test. This is not official GL Assessment material and is not endorsed by GL Assessment or Kent County Council.

## Run locally
Open `index.html` in a browser. No build step or server needed.

## Check the question bank
```
node validate.js
```
